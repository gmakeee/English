# Как добавить свои слова в LizaLingo

## Формат JSON

Слова хранятся в файле `src/data/words.ts`. Вот формат:

```typescript
{
  id: 1,                          // Уникальный номер
  word: "beautiful",              // Английское слово
  translation: "красивый",        // Русский перевод
  example: "She is beautiful.",   // Пример использования
  options: [                      // 4 варианта для квиза (включая правильный)
    "красивый",    // ← правильный
    "умный",       // неправильные
    "большой",
    "маленький"
  ]
}
```

## Как добавить слова

1. Открой файл `src/data/words.ts`
2. Найди массив `WORDS_A2_B1`
3. Добавь новые слова в конец массива:

```typescript
{ id: 51, word: "amazing", translation: "удивительный", example: "This is amazing!", options: ["удивительный", "скучный", "плохой", "грустный"] },
{ id: 52, word: "believe", translation: "верить", example: "I believe in you.", options: ["сомневаться", "верить", "забывать", "помнить"] },
```

## Формат для предложений (Fill-in-Gap)

```typescript
{
  id: 1,
  sentence: "I need to ___ my English.",  // ___ = пробел
  correctWord: "improve",
  options: ["improve", "forget", "ignore", "lose"]
}
```

## Формат для диктанта

Просто список слов:
```typescript
["beautiful", "important", "understand", "remember"]
```

## Что это даёт

| Плюс | Описание |
|------|----------|
| **Контроль** | Ты выбираешь слова под уровень A2/B1 |
| **Переводы** | API не дают русский, а твои слова — да |
| **Offline** | Работает без интернета |
| **Персонализация** | Можно добавить слова по темам |

## API обогащают слова

Datamuse и Dictionary API дополняют твои слова:

- **Синонимы** → для генерации неправильных вариантов
- **Произношение** → аудио для диктанта
- **Примеры** → дополнительные предложения
- **Определения** → для продвинутого режима

Твоя база = основа, API = бонусы.
